# docs/integrations

用途：与外部系统、求解器、ML 工具、数据库和运行后端的集成说明。

边界：

- 这里说明外部能力如何通过正式 provider / plugin / runtime / inner Case surface 接入。
- 不在这里定义 nsgablack 或 mlblack 的核心架构规则。
- 不把外部 backend 的私有流程塞进 Adapter、Solver 或 example 脚本。

示例：

- `ML_FRAMEWORK_INTEGRATION.md`
- `COPT_INTEGRATION.md`
- `COPT_Python_Only_CN.md`
