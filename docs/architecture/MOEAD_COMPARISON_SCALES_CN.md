# MOEA/D 比较尺度与方向子池

`MOEADAdapter(objective_scales=(100000.0, 1.0, 1.0, 1.0))` 显式声明每个原始目标的比较尺度。
这是算法比较规则，Problem、原始反馈、池内原始目标和 ideal point 仍保存原单位。
未配置时保持原有比较行为。

## 同一个方向必须使用同一规则

设方向权重为 `w`，尺度为 `s`。MOEA/D 替换比较使用有效权重 `w / s`：

- weighted sum：`sum((w / s) * f)`。
- Tchebycheff：`max((w / s) * abs(f - ideal))`。

Adapter 发布的 `ObjectiveProjection` 使用同一有效权重和原单位参考点。因此 VNS 消费该方向子池时，
起点和新邻域的比较与发布者一致；不需要改写子池候选的原始目标，也不需要修改投影 schema。
返回 MOEA/D 后，由其当前 ideal、方向和替换规则重新竞争，不能把冻结投影分数当作母池新目标。

尺度的长度必须与 Problem 目标数相同，每项有限且严格为正，除法结果也必须有限。
装配/启动时拒绝不合法配置，不等待评估后再报错。选择组件获得原方向权重、ideal 和
`objective_scales`，同时获得实际用于替换的 scores。

## 恢复边界

checkpoint 保存显式尺度，恢复时必须与当前装配一致。旧 checkpoint 未声明尺度时，
只允许在未配置尺度的旧比较规则下恢复；不推断或自动迁移。步骤事务沿用同一个状态协议。

## 排程装配中的含义

生产排程保留原始四目标，`--objective-output-scale 100000` 只缩放产量轴的比较单位。
它不会证明这个权衡最符合业务偏好。产量、稳定性和归一化折中应分别交付，结合完整数据上的
基线、多随机种子、实际求值成本和整数排程复核判断质量。

行为验收位于 `tests/test_moead_objective_scales.py`：替换与方向视图一致、raw 保留、量级改变选择、
启动前维度校验、数值溢出拒绝及 checkpoint 比较框架保护。
